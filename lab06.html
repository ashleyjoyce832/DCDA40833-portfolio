Lab 6: Python Mapping

Python Map Visualization

Reflection

Design Inspiration

The design of my map was inspired by 90's vogue covers. I wanted to encapsulate the period of fashion I love. I used neutral colors, grunge-inspired moody tones, and a few pops for the early 90's. I used a Vogue font I downloaded for countries, states, and major cities. I used an earthly olive green to denote national parks, as I grew up going to many on family vacation. I choose to show less hillshade, because Houston, and Texas as a whole is pretty flat. I made sure roads and subdivisions were clearly marked, because around Houston, often where you are located within the highway "loops" and which neighborhood you are in matter to understand where you are talking about, because everything is so far apart.

Cartographic Challenges

I think creating hierarchy with fonts and color took some adjusting too, but with my design background I was able to apply those principles to the map design. I wanted to make sure at the closest zoom labels to show as much info as possible, on key places and roads, but make sure the map wasn't too cluttered as you zoom out. A few things were the cities that are shown vs. hidden as you scroll out might be something I would change to show certain cities over others.

Technical Challenges

After exploring vibe coding and learning how to effectively utilize AI tools, I've learned to effectively prompt my code to create what I need it to. I still am working to understand the code and write portions on my own. I had to troubleshoot downloading some new software to be able to complete this assignment, but was eventually successful in making sure I had all the right tools to be successful.
